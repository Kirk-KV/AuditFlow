# Получение обратной связи

Сформировано: $generated_date

Аудит: $audit_name

Папки:

- `request/` - тексты писем для отправки получателям.
- `response/` - YAML-шаблоны, которые аудитор заполняет после получения ответов.
- `response/original/` - исходные ответы менеджмента в формате `.eml`, `.msg`, `.pdf` или снимков экрана.

Порядок работы:

1. Откройте соответствующий `*_request.txt` и отправьте текст получателю.
2. Сохраните исходный ответ в `response/original/`.
3. Заполните соответствующий `*_response.yml`.
4. Выполните `auditflow feedback summary`.
5. Проверьте `08_feedback/feedback_summary.qmd`.

Файлы запросов можно пересоздать с параметром `--overwrite`. Шаблоны ответов
сбрасываются только при явном использовании `--reset-response-templates`.
