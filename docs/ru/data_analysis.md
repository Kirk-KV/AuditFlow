# Воспроизводимый анализ данных

[English](../data_analysis.md) | **Русский**

## Разделение файлов

- исходные выгрузки: `04_evidence/02_raw_data/`;
- скрипты получения и анализа: рядом с данными или в согласованной папке команды;
- результаты анализа: `04_evidence/99_generated/`;
- интерпретация результатов: соответствующий workpaper.

Не изменяйте исходную выгрузку вручную. Очистку, объединение и фильтрацию выполняйте кодом, чтобы процедуру можно было повторить.

## Минимальная цепочка

```text
raw data -> script/query -> generated output -> workpaper -> observation
```

Рабочий документ должен ссылаться на фактически использованные данные и результаты через обычные Markdown-ссылки. Валидатор проверяет локальные ссылки внутри `04_evidence`.

Для примера установите аналитические зависимости:

```powershell
pip install -e ".[analysis]"
```

Quarto использует Python из активного окружения. При необходимости задайте его явно:

```powershell
$env:QUARTO_PYTHON = "C:/path/to/env/python.exe"
quarto preview 05_workpapers/WP-C-001.qmd
```
